# Horizon pour Android

Application de tapis de course : parcours en 3D, séances guidées, défi contre ton record,
test d'allures, badges, mode zen, éditeur de séances, calibrage, liaison montre et Intervals.icu.

## Obtenir l'application (une seule fois)
1. Crée un compte gratuit sur github.com.
2. « New repository », nom : horizon, Public, puis « Create repository ».
3. « uploading an existing file » : glisse TOUT le contenu de ce dossier, puis « Commit changes ».
4. Onglet Actions : la construction démarre seule (environ 6 minutes).
5. Settings > Pages > Source : « GitHub Actions » (pour les liens de défi).
6. Sur ton téléphone : github.com/TON-NOM/horizon/releases, touche Horizon.apk, installe.
   Android demandera d'autoriser l'installation depuis Chrome : accepte.

## Mettre à jour
Remplace le fichier www/index.html dans GitHub : une nouvelle version apparaît dans Releases.
Installe-la par-dessus l'ancienne, tes parcours, records et badges sont conservés.
